# Blinkit Landing Page Clone

A static, responsive clone of the Blinkit homepage built using only HTML5 and CSS3. The page demonstrates semantic markup, Flexbox, CSS Grid, and media queries to adapt to desktop, tablet, and mobile screens.

## Project Structure
```
blinkit-clone/
├─ index.html   # Main page with all sections
├─ style.css    # Styling (Flexbox, Grid, breakpoints)
├─ assets/      # Images and icons (e.g., logo.svg)
└─ screenshots/ # Example screenshots (desktop & mobile)
```

## Technologies
- **HTML5** – semantic elements (`header`, `nav`, `main`, `section`, `footer`).
- **CSS3** – custom properties, Flexbox, Grid, media queries.
- No JavaScript or external libraries.

## Running the Project
1. Open the `blinkit-clone` folder.
2. Double‑click `index.html` (or run `start index.html` in PowerShell).
3. The page loads locally; no server is required.
